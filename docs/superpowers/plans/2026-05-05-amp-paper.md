- [ ] **Step 2: Write §3.1 Three-Layer Architecture (~400 words)**

Subsection content:

```latex
\section{Method}
\label{sec:method}

\subsection{Three-Layer Architecture}

AMP organizes agent memory into three layers, mirroring the distinction between working memory and episodic long-term memory in cognitive psychology~\citep{baddeley2003working}.

\paragraph{Short-Term Memory (STM).} Every interaction turn $t = (\text{role}, \text{content}, \text{timestamp})$ is appended verbatim to a per-session buffer. The STM is a high-fidelity FIFO log: no summarization, no rewriting. This preserves the conversational narrative needed for multi-hop reasoning.

\paragraph{Long-Term Memory (LTM).} When the STM exceeds a threshold $\tau_{\text{stm}}$ turns (default $\tau_{\text{stm}} = 50$), a consolidation step (\Cref{alg:consolidate}) emits a compact insight $m_i$ embedded by $\phi: \mathcal{T} \to \mathbb{R}^{384}$ (we use \texttt{bge-small-en-v1.5}). Insights are persisted to SQLite with the embedding stored as a BLOB.

\paragraph{Graph Layer.} A lightweight entity graph $G = (V, E)$ tracks named entities (extracted via the LLM during consolidation) as nodes; edges are co-occurrence within a sliding window. Edge weights accumulate with frequency.
```

```latex
\subsection{Retrieval}

Given a query $q$, we compute query embedding $v_q = \phi(q)$ and rank LTM insights by:
\[
\text{score}(m_i, q) = \alpha \cdot \cos(v_q, v_i) + \beta \cdot r(m_i) + \gamma \cdot \mathbb{1}[E_q \cap E_{m_i} \neq \emptyset]

The final retrieved context concatenates: top-$k$ LTM insights + entire STM buffer + neighborhood of matched entities in $G$ (1-hop).
```

```python
import json
import requests
from typing import Literal

JUDGE_PROMPT = """You are an impartial judge. Decide whether the PREDICTION correctly answers the QUESTION given the GROUND TRUTH.

Be generous: paraphrases, partial answers that capture the essential fact, and equivalent phrasings count as CORRECT. Only mark WRONG if the prediction is empty, hallucinated, contradicts the ground truth, or misses the key fact entirely.

QUESTION: {question}
GROUND TRUTH: {ground_truth}
PREDICTION: {prediction}

Respond with exactly one word: CORRECT or WRONG."""


class LocalJudge:
    def __init__(self, model: str, host: str = "http://localhost:11434"):
        self.model = model
        self.host = host

    def score(self, question: str, ground_truth: str, prediction: str) -> Literal[0, 1]:
        if not prediction or not prediction.strip():
            return 0
        prompt = JUDGE_PROMPT.format(
            question=question, ground_truth=ground_truth, prediction=prediction
        )
        resp = requests.post(
            f"{self.host}/api/generate",
            json={"model": self.model, "prompt": prompt, "stream": False, "options": {"temperature": 0.0}},
            timeout=120,
        )
        resp.raise_for_status()
        text = resp.json()["response"].strip().upper()
        return 1 if text.startswith("CORRECT") else 0
```

```python
from typing import Sequence
from sklearn.metrics import cohen_kappa_score


def kappa(judge_a: Sequence[int], judge_b: Sequence[int]) -> float:
    """Cohen's kappa between two binary judges."""
    assert len(judge_a) == len(judge_b)
    return float(cohen_kappa_score(judge_a, judge_b))


def agreement_rate(judge_a: Sequence[int], judge_b: Sequence[int]) -> float:
    """Raw agreement fraction."""
    assert len(judge_a) == len(judge_b)
    return sum(a == b for a, b in zip(judge_a, judge_b)) / len(judge_a)
```

```python
from amp.core.llm import OllamaProvider


class AMPSystem:
    name = "AMP"

    def __init__(self, model: str = "llama3.1:8b"):
        self.client = AMPClient()
        self.llm = OllamaProvider(model=model)

    def reset(self) -> None:
        self.client.clear()

    def ingest(self, conversation_id: str, role: str, content: str, timestamp: str) -> None:
        self.client.write(content=content, role=role, session_id=conversation_id, timestamp=timestamp)

    def query(self, conversation_id: str, question: str) -> str:

        prompt = f"Use the following memory to answer.\n\nMEMORY:\n{context}\n\nQUESTION: {question}\n\nANSWER:"
        return self.llm.generate(prompt)
```

```python
    def ingest(self, conversation_id: str, role: str, content: str, timestamp: str) -> None:
        self.mem.add(content, user_id=conversation_id)

    def query(self, conversation_id: str, question: str) -> str:
        results = self.mem.search(question, user_id=conversation_id, limit=10)
        # Defensive: handle both list-of-dict and list-of-str shapes that Mem0 has shipped
        if results and isinstance(results[0], dict):
            ctx = "\n".join(r.get("text", r.get("memory", "")) for r in results)
        else:
            ctx = "\n".join(str(r) for r in results)
        prompt = f"MEMORY:\n{ctx}\n\nQUESTION: {question}\n\nANSWER:"
        return self.llm.generate(prompt)
```

```python
from fastembed import TextEmbedding
import numpy as np
from amp.core.llm import OllamaProvider


class RAGSystem:
    name = "RAG"

    def __init__(self, model: str = "llama3.1:8b", chunk_size: int = 200):
        self.embedder = TextEmbedding(model_name="BAAI/bge-small-en-v1.5")
        self.llm = OllamaProvider(model=model)
        self.chunk_size = chunk_size
        self.store: dict[str, list[tuple[str, np.ndarray]]] = {}

    def reset(self) -> None:
        self.store = {}

    def ingest(self, conversation_id: str, role: str, content: str, timestamp: str) -> None:
        text = f"{role}: {content}"
        chunks = [text[i:i+self.chunk_size] for i in range(0, len(text), self.chunk_size)]
        embs = list(self.embedder.embed(chunks))
        self.store.setdefault(conversation_id, []).extend(zip(chunks, embs))

    def query(self, conversation_id: str, question: str) -> str:
        if conversation_id not in self.store:
            return ""
        q_emb = next(self.embedder.embed([question]))
        scored = [(np.dot(q_emb, e), c) for c, e in self.store[conversation_id]]
        scored.sort(reverse=True)
        ctx = "\n".join(c for _, c in scored[:10])
        prompt = f"MEMORY:\n{ctx}\n\nQUESTION: {question}\n\nANSWER:"
        return self.llm.generate(prompt)
```

```python
import numpy as np
from typing import Sequence


def bootstrap_mean_ci(scores: Sequence[float], n_resamples: int = 10_000, alpha: float = 0.05, seed: int = 42) -> tuple[float, float, float]:
    """Returns (mean, ci_low, ci_high) at (1-alpha) confidence."""
    rng = np.random.default_rng(seed)
    arr = np.asarray(scores, dtype=float)
    means = np.array([rng.choice(arr, size=len(arr), replace=True).mean() for _ in range(n_resamples)])
    return float(arr.mean()), float(np.quantile(means, alpha / 2)), float(np.quantile(means, 1 - alpha / 2))
```

```python
"""Read raw results CSVs, emit paper-ready summary CSVs and LaTeX table fragments."""
import argparse
import csv
from pathlib import Path
import pandas as pd
from benchmarks.analysis.bootstrap_ci import bootstrap_mean_ci
from benchmarks.judges.agreement import kappa, agreement_rate


def summarize_main(results_csv: Path, out_dir: Path):
    df = pd.read_csv(results_csv)
    judge_cols = [c for c in df.columns if c.startswith("judge_")]
    df["mean_judge"] = df[judge_cols].mean(axis=1)

    rows = []
    for system, sub in df.groupby("system"):
        m, lo, hi = bootstrap_mean_ci(sub["mean_judge"].tolist())
        rows.append({"system": system, "accuracy": m, "ci_low": lo, "ci_high": hi, "n": len(sub)})
    out_df = pd.DataFrame(rows).sort_values("accuracy", ascending=False)
    out_df.to_csv(out_dir / "main_results_summary.csv", index=False)

    # Per-category
    cat_rows = []
    for (system, cat), sub in df.groupby(["system", "category"]):
        m, lo, hi = bootstrap_mean_ci(sub["mean_judge"].tolist())
        cat_rows.append({"system": system, "category": cat, "accuracy": m, "ci_low": lo, "ci_high": hi, "n": len(sub)})
    pd.DataFrame(cat_rows).to_csv(out_dir / "per_category_summary.csv", index=False)

    # Judge agreement
    if len(judge_cols) >= 2:
        ja, jb = df[judge_cols[0]].tolist(), df[judge_cols[1]].tolist()
        with (out_dir / "judge_agreement.txt").open("w") as f:
            f.write(f"kappa: {kappa(ja, jb):.4f}\n")
            f.write(f"raw_agreement: {agreement_rate(ja, jb):.4f}\n")
            f.write(f"n: {len(ja)}\n")


def emit_latex_main_table(summary_csv: Path, out_tex: Path):
    df = pd.read_csv(summary_csv)
    lines = [r"\begin{tabular}{lc}", r"\toprule", r"System & Accuracy (95\% CI) \\", r"\midrule"]
    for _, r in df.iterrows():
        lines.append(f"{r['system']} & {r['accuracy']*100:.1f} ({r['ci_low']*100:.1f}, {r['ci_high']*100:.1f}) \\\\")
    lines.extend([r"\bottomrule", r"\end{tabular}"])
    out_tex.write_text("\n".join(lines))


if __name__ == "__main__":
    p = argparse.ArgumentParser()
    p.add_argument("--results", type=Path, required=True)
    p.add_argument("--out-dir", type=Path, required=True)
    args = p.parse_args()
    args.out_dir.mkdir(parents=True, exist_ok=True)
    summarize_main(args.results, args.out_dir)
    emit_latex_main_table(args.out_dir / "main_results_summary.csv", args.out_dir / "main_results.tex")
```

```latex
\section{Introduction}
\label{sec:intro}

LLM-based agents are increasingly deployed in long-horizon settings: coding assistants that carry knowledge across days~\citep{...}, research assistants that span weeks of inquiry, and personal agents that learn user preferences over months. In every such setting, the agent must remember.

The naive approach — fitting all history in the model's context window — fails on three fronts: cost scales linearly with history, attention degrades with the lost-in-the-middle effect~\citep{liu2024lost}, and most production deployments cannot afford 128k-token prompts per turn. The standard alternative, retrieval-augmented generation~\citep{lewis2020rag}, retrieves chunks from a vector store but treats every chunk as independent: the conversational thread is destroyed.

Recent agent memory systems take an \emph{extraction-first} approach: summarize conversations into discrete facts and store those~\citep{mem0}. This compresses aggressively but throws away the very narrative structure that gives a conversation meaning. A user telling an agent ``I'm worried about the launch on Thursday because the on-call team is short-staffed'' contains a chain of reasoning that, once flattened to ``Thursday launch'' and ``team short-staffed'', cannot be reconstructed.

We argue that long-horizon agent memory should be \emph{context-first}: preserve turns at high fidelity, then consolidate strategically rather than eagerly. We instantiate this thesis in \textbf{AMP}, the Agent Memory Protocol — a memory system with three layers (short-term buffer, consolidated long-term store, entity graph) exposed as a Model Context Protocol server.

\paragraph{Contributions.}
\begin{enumerate}
    \item \textbf{The AMP architecture} (Section~\ref{sec:method}): a three-layer cognitive-architecture-inspired memory system with explicit STM/LTM separation and a complementary entity graph.
    \item \textbf{An open protocol surface}: the first MCP-native specification for agent memory operations (\texttt{write\_memory}, \texttt{query\_memory}, \texttt{consolidate}), enabling drop-in use from Claude Desktop, Cursor, and other MCP clients.
    \item \textbf{Empirical evidence} (Section~\ref{sec:experiments}): on the full LoCoMo benchmark, AMP achieves \textsc{TBD}\% accuracy versus \textsc{TBD}\% for the strongest baseline. Component ablation isolates LTM consolidation as the single largest contributor, with the entity graph providing an additional gain on multi-hop questions.
    \item \textbf{Open-source release}: code, data, scripts, and trained-on-nothing reproducibility (local Ollama models) at \url{https://github.com/akshayaggarwal99/amp}.
\end{enumerate}
```

```latex
\section{Discussion}
\label{sec:discussion}

\paragraph{Why does Context-First win?} The largest gaps appear on multi-hop and temporal questions (\Cref{fig:percat}). These question types require chains of reasoning across turns — exactly the structure that extraction-first systems flatten away. AMP's STM preserves the turn-level chain verbatim; consolidation summarizes \emph{additionally} rather than \emph{instead of} the raw record.

\paragraph{When does Extraction-First suffice?} On single-hop simple-fact questions, both AMP and extraction-first systems perform comparably. If an application is dominated by such queries, the additional storage cost of preserving turns may not be justified.

\paragraph{Reproducibility on commodity hardware.} All experiments ran on a single MacBook Pro with no API calls. This is intentional: long-horizon agents will be deployed at the edge, and a memory system that requires cloud infrastructure cannot serve those settings.

\paragraph{Mem0 reproduction.} During our evaluation, the Mem0 client API surface changed across patch versions: \texttt{Memory.search} returned \texttt{list[str]} in some configurations and \texttt{list[dict]} in others. We pinned to version \texttt{TBD} and report numbers from that version. We do not claim that Mem0's underlying approach is faulty — only that the deployment-stable behavior of the version tested produced the numbers reported.

\section{Limitations}

We evaluate on a single benchmark (LoCoMo). Generalization to other long-horizon settings (multi-day coding tasks, multi-week research projects) is unproven. Both LLM judges are open-weights local models; though they agree at $\kappa = $ \textsc{TBD}, both could share systematic biases not captured by inter-judge agreement. We did not compare against MemGPT~\citep{memgpt} or Letta directly because of integration cost within the one-week author timeline; we leave these comparisons to extended work. Finally, this is a sole-author preprint without peer review.
```
